Render benchmark

The same pictures rendered by the CPU reference, by a pool of workers, and by this machine's GPU — with how long each took and how far the GPU's pixels are from the reference's. Everything runs in this page; nothing is uploaded. When it has finished, copy the text at the bottom.

Workers

A busy 1920 × 1080 video frame (every tile changes every frame) and a still picture of eight nodes, rendered by one engine and by 1…N helper workers, each with its own instance of the engine. The pixels must be identical; the time should fall.

CPU and GPU

A comp whose nodes all have kernels (exposure, two gradients blended over, a blur, a transform, a grade through a table, a sharpen), rendered at full size by the reference and by WebGPU. N↔G is what you would see differ; K↔G is what this GPU's arithmetic adds to the same program run on the CPU.

Kernel by kernel

One small picture per kind of kernel (640 × 360), three ways: the reference (N), the kernel on the CPU (K), the kernel on the GPU (G). Counts are pixels that differ after cooking back to 8 and 16 bits, laid over black.
